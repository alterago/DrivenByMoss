# REAPER Push Karaoke

This fork adds a full-width lyrics mode for Push 3 when DrivenByMoss runs in
REAPER. The Push Learn/light-bulb button toggles the mode:

- first press: show previous, current, and next lyrics;
- second press: restore the previously active DrivenByMoss screen.

The mode reads a tiny UTF-8 snapshot generated by the companion
`Pasha_Push Lyrics bridge.lua` ReaScript from the `reaper-addons` repository.
The snapshot lives at:

```text
~/Library/Application Support/REAPER/Cache/PashaLyricsPush.tsv
```

The public DrivenByMoss repository contains the shared controller code but not
the complete native REAPER wrapper. `tools/build-reaper-karaoke-patch.sh`
therefore compiles only the changed shared classes against the official REAPER
JAR and overlays them onto a copy. It never replaces the installed JAR itself.

```sh
./tools/build-reaper-karaoke-patch.sh \
  "$HOME/Library/Application Support/REAPER/UserPlugins/drivenbymoss-libs/DrivenByMoss4Reaper-26.6.5.jar" \
  "$PWD/target/DrivenByMoss4Reaper-26.6.5-pasha-lyrics.jar"
```

Back up the official JAR, install the generated copy while REAPER is closed,
then restart REAPER. The patch is version-specific and must be rebuilt against
the exact installed DrivenByMoss version.
